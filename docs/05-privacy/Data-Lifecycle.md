# دورة حياة البيانات (Data Lifecycle: Retention & Deletion)

> الحالة: Draft · آخر تحديث: 2026-11-15 · الاحتفاظ المقترح يحتاج تأكيداً قانونياً (OQ-002، OQ-013).

## 1. المراحل

| المرحلة | البيانات الصحية (D-01..D-05) | بيانات تشغيلية/أدمن |
|---|---|---|
| الجمع | بإجراء صريح من المستخدم بعد الإشعار/الموافقة | تلقائي (عدادات) / إنشاء حساب بواسطة Super Admin |
| المعالجة | في طلب واحد؛ في الذاكرة | — |
| التخزين | **لا يوجد** على الخادم | الجداول الموثقة |
| المشاركة | D-05 فقط إلى Google بعد المرشحات | لا |
| الحذف | تلقائي بانتهاء الطلب/الصفحة؛ يدوي بزر "امسح كل شيء" | مجدول (أدناه) |

## 2. جدول الاحتفاظ والحذف

| البيانات | الاحتفاظ | آلية الحذف | المسؤول |
|---|---|---|---|
| حالة التقييم في المتصفح | حتى إغلاق/تحديث/مسح | Garbage collection + زر المسح + Quick Exit | الواجهة |
| الجلسة العامة | 30 دقيقة خمول | انتهاء TTL في Redis / GC للـ file driver | Laravel |
| `localStorage` (FR-095 اختياري) | حتى يحذفه المستخدم | زر "احذف من هذا الجهاز" + "امسح كل شيء" | الواجهة |
| مفاتيح حدود المعدل (IP مجزّأ) | ≤ 24 ساعة | TTL | Redis |
| `ai_usage_logs` | 90 يوماً | `rafiq:prune` يومياً: تجميع إلى `daily_metrics` ثم حذف | Scheduler |
| `daily_metrics` | غير محدد | — (مجمّع) | — |
| `audit_logs` | 24 شهراً | `rafiq:prune` | Scheduler |
| `failed_jobs` | 7 أيام | `queue:prune-failed --hours=168` | Scheduler |
| `cache` (database store إن بقي) | حسب TTL | `cache:prune-stale-tags` / GC | Scheduler |
| حسابات الأدمن المعطلة | 12 شهراً بعد التعطيل | حذف يدوي بواسطة Super Admin مع الإبقاء على `actor_id` في السجل كمرجع مجهول (`deleted admin #id`) | Super Admin |
| سجلات تطبيق Laravel (`storage/logs`) | 14 يوماً | `daily` channel مع `days=14` | Laravel |
| سجلات خادم الويب | هدف ≤ 14 يوماً | إعداد الاستضافة | DevOps (OQ-011) |
| بيانات Google (D-05) | وفق شروط Google | خارج سيطرتنا — يُفصح عنه (PRIV-007) | — |
| النسخ الاحتياطية | 30 يوماً (مقترح) | تدوير | DevOps |

## 3. أمر `rafiq:prune`

- يعمل يومياً (`schedule` مع `withoutOverlapping()` و`onOneServer()`).
- يحذف على دفعات (chunked) لتجنب الأقفال الطويلة.
- يكتب ملخصاً (عدد الصفوف المحذوفة لكل جدول) في السجل دون أي محتوى.
- مختبر بـ Feature test باستخدام `travel()` لمحاكاة مرور الزمن.

## 4. الحذف بطلب المستخدم

- **المستخدم العام:** لا بيانات مخزنة مرتبطة به؛ "امسح كل شيء" ينهي الجلسة ويمسح الحالة المحلية.
- **الأدمن:** طلب حذف الحساب يُنفذ بعد التحقق، مع الإبقاء على سجل التدقيق مجهولاً بالمرجع (لغرض المساءلة) ضمن مدة الاحتفاظ.
