## 3. المحتوى والإعدادات (S0–S1)

المقالات، الترجمات، المراجعات، المصادر، المقاطع، المسرد، بنك الأسئلة، القواعد وإصداراتها، الإصدارات، نصوص الإرشاد، إعدادات الـ AI — **دائمة** (سجل سلامة)، تُؤرشف ولا تُحذف بعد النشر.

## 4. البيانات المحظورة (لا تُجمع أبداً)

اسم المستخدم العام، الهاتف، البريد، الهوية الوطنية، العنوان، تاريخ الميلاد، الموقع الجغرافي الدقيق، الصور، الملفات المرفوعة، قيم الفحوص المخبرية، معرفات الإعلانات، بصمات المتصفح، معرف ثابت للزائر.
