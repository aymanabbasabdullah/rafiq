## 1. حالات القاعدة ودورة الحياة

`Draft` → `Pending Medical Review` → `Approved` → (`Retired`)
الرفض يعيد إلى `Draft` مع تعليق إلزامي. أي تعديل على قاعدة `Approved` ينشئ **إصداراً جديداً** بحالة `Draft`؛ الإصدار المعتمد السابق يبقى في الـ Release المنشور حتى نشر إصدار جديد. التفاصيل في [Clinical-Review-Process](Clinical-Review-Process.md).

### `ss_fever_with_pain_or_swelling = unsure` / `ss_new_lump_or_change = unsure`
- مقترح: `unsure` على سؤال الحمّى ⇒ P2 + نص "إذا تأكدت من وجود حمّى، اطلب تقييماً اليوم" [مراجعة].
- مقترح: `unsure` على سؤال الكتلة ⇒ P3 + محتوى "كيف تفحص نفسك" + "راجع طبيباً إن لاحظت تغيراً" [مراجعة].
- `ss_current_pain_or_swelling = unsure` ⇒ يُعامل كـ yes لغرض إظهار الأسئلة التالية فقط (لا أولوية بذاته).
