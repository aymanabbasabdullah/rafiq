# إطار السلامة السريرية (Clinical Safety Framework)

> **DRAFT – PENDING QUALIFIED MEDICAL REVIEW**
> آخر تحديث: 2026-11-15 · لا يُعتبر هذا الإطار معتمداً طبياً. المصادر: [Medical-Sources-Register](Medical-Sources-Register.md).

## 1. الغرض والنطاق

يحدد هذا الإطار كيف تضمن رفيق أن التوجيه الصحي **آمن، حتمي، قابل للاختبار، قابل للمراجعة**، وأن المنصة تبقى أداة توعية وإرشاد لا أداة تشخيص.

**داخل النطاق:** Safety Screening، Assessment، Clinical Rules Engine، Guidance texts، رسائل الطوارئ في الـ AI (Red-flag interceptor)، صفحة Under-18، رسالة السلامة العامة.
**خارج النطاق:** التشخيص، التفسير المخبري، العلاج، أي قرار سريري بواسطة LLM.

## 2. المبادئ السريرية

| # | المبدأ | التطبيق |
|---|---|---|
| CS-1 | **السلامة أولاً** | أسئلة علامات الخطر قبل أي سؤال آخر؛ P0 يقطع التدفق. |
| CS-2 | **أعلى أولوية تفوز** | لا "متوسط" ولا "مجموع نقاط"؛ النتيجة = max(priority). |
| CS-3 | **التحفّظ عند عدم اليقين** | "لست متأكداً" لا يُعامل كـ "لا" في أسئلة الخطر (SAFE-006، OQ-009). |
| CS-4 | **لا طمأنة زائفة** | لا عبارة "لا داعي للقلق" أو "طبيعي"؛ P4 يعني "لم تظهر من إجاباتك حاجة لخطوة محددة، ونشجعك على …" مع حدود واضحة. |
| CS-5 | **الحتمية** | لا عشوائية، لا LLM، لا تأثير للغة أو الجهاز على النتيجة. |
| CS-6 | **قابلية التتبع** | كل نتيجة تُرجع إصدار الـ Ruleset ومعرفات القواعد المفعلة. |
| CS-7 | **الاعتماد قبل التشغيل** | لا قاعدة في Production قبل `Approved`. |
| CS-8 | **المصدر لكل قاعدة** | تصنيف [مصدر]/[استنتاج]/[مراجعة] إلزامي. |
| CS-9 | **ثنائية لغة مراجَعة** | كل نص إرشاد يُعتمد لكل لغة. |
| CS-10 | **التكيف المحلي** | الخطوات العملية (رقم الطوارئ، نوع المنشأة) حسب البلد المعتمد (OQ-008). |

## 3. مستويات الأولوية

| المستوى | الاسم (ar / en) | المعنى للمستخدم (مسودة) | الإجراء في الواجهة |
|---|---|---|---|
| **P0** | طوارئ / Emergency | "قد تكون هذه حالة تحتاج علاجاً عاجلاً في المستشفى. اتصل بالطوارئ أو اذهب إلى أقرب قسم طوارئ الآن." | شاشة كاملة، رقم الطوارئ بارز، تعليمات معتمدة، **إيقاف التدفق**. |
| **P1** | عاجل / Urgent | "يُنصح بتقييم طبي في نفس اليوم." | شاشة بارزة، خيار متابعة القراءة. |
| **P2** | تقييم سريري / Clinical Evaluation | "يُنصح بحجز موعد مع طبيب لمناقشة هذا." (مع "قريباً" عند الحساسية الزمنية) | تقرير + Doctor Prep. |
| **P3** | وقائي / Preventive | "هناك عوامل يمكنك مناقشتها مع طبيبك أو العمل عليها في نمط حياتك." | تقرير + محتوى. |
| **P4** | معلوماتي / Informational | "لم تُظهر إجاباتك حاجة لخطوة طبية محددة الآن. هذا ليس تأكيداً لسلامتك؛ راجع الطبيب إن ظهرت أعراض أو استمر قلقك." | تقرير + محتوى. |
| **GATE** | غير مؤهل | (CR-001) خارج الفئة العمرية | صفحة Under-18. |

> الصياغات أعلاه مسودات **[مراجعة]** وتُستبدل بنصوص `guidance_texts` المعتمدة.

## 4. نموذج القاعدة (Rule Model)

```json
{
  "code": "CR-002",
  "version": 1,
  "title": "Sudden severe testicular pain",
  "section": "safety",
  "journeys": ["concern", "conception"],
  "when": { "all": [ { "q": "ss_sudden_severe_pain", "op": "eq", "value": "yes" } ] },
  "outcome": { "priority": "P0", "stop": true, "flags": [] },
  "guidance_keys": ["guidance.p0.emergency", "guidance.p0.dont_drive", "guidance.p0.bring_meds"],
  "doctor_topic_keys": [],
  "related_article_keys": ["testicular-pain-when-urgent"],
  "evidence": [ { "source": "SRC-001", "support": "direct" } ],
  "status": "draft"
}
```

**العوامل المسموحة (`op`):** `eq`, `neq`, `in`, `not_in`, `contains` (multi), `contains_any`, `is_unsure`, `is_answered`, `is_unanswered`, `band_gte`, `band_lte`. **المجمّعات:** `all`, `any`, `not`. لا تعابير حرة ولا كود.

## 5. خوارزمية التقييم

1. التحقق من أن Ruleset نشط ومسموح بالبيئة (ADR-006).
2. التحقق من المدخلات ضد تعريفات الأسئلة (المفاتيح، القيم، الإلزامية، التنافي بين `none` وغيره) ⇒ أي خطأ = 422 (لا حساب).
3. **CR-001 (GATE)** أولاً: إذا `age_confirmed != true` ⇒ نتيجة GATE.
4. تقييم قواعد `section=safety` بالترتيب؛ إن ظهرت P0 مع `stop=true` ⇒ إرجاع فوري (النتيجة تحتوي كل قواعد السلامة المفعّلة لأغراض الاختبار).
5. تطبيق سياسة "لست متأكداً" (SAFE-006).
6. تقييم قواعد `section=assessment` المنطبقة على `journey`.
7. `priority = max(triggered.priority)`؛ إذا لا قواعد ⇒ P4.
8. تجميع `guidance_keys` مرتبة حسب الأولوية ثم رمز القاعدة، دون تكرار؛ و`doctor_topic_keys`؛ و`flags` (مثل `time_sensitive`, `show_emergency_criteria`, `unanswered_present`).
9. إرجاع `EvaluationResult` غير قابل للتغيير — **لا تخزين**.

## 6. معالجة الحالات الخاصة

| الحالة | السلوك | مرجع |
|---|---|---|
| سؤال خطر بلا إجابة | 422 | SAFE-007 |
| إرسال مبكر (جزئي) بعد إجابة "نعم" على سؤال P0 | مقبول **فقط** إذا كانت الإجابات المرسلة تفعّل P0 ⇒ P0 فوراً؛ أي إرسال جزئي آخر ⇒ 422 | M04-FR-03، TC-36/37 |
| "لست متأكداً" على سؤال P0 | P1 + `show_emergency_criteria` | SAFE-006 / OQ-009 |
| "لا أعرف" في سؤال تقييم | لا يفعّل القاعدة؛ يضيف موضوعاً للطبيب "أسئلة لم أعرف إجابتها" | CR-specific |
| سؤال تقييم متخطى | لا يفعّل؛ `unanswered_present` | FR-041 |
| تعارض (مثلاً `none` + خيار) | 422 | TC-24 |
| قيم مزورة/مفاتيح زائدة | 422 | TC-22/23 |
| خطأ داخلي في المحرك | 503 + SAFE-009 (لا افتراض منخفض) | SEC-014 |
| لا Ruleset منشور (Production) | 503 + SAFE-009 | FR-052 |

## 7. المحتوى الممنوع في نصوص الإرشاد (SAFE-010)

قاموس فحص آلي (ar/en) يشمل على الأقل: "تشخيص/diagnosis" بصيغة الحكم، "أنت مصاب/you have [condition]"، "عقيم/infertile" كحكم، "خصوبتك طبيعية/your fertility is normal"، "لا داعي للقلق/nothing to worry about"، أي نسبة مئوية للخصوبة، أسماء أدوية مع جرعات، "توقف عن تناول/stop taking". يُفحص في CI على `guidance_text_translations` المستوردة وعلى ملفات الـ seed.

## 9. التصنيف التنظيمي (تنبيه)

قد تعتبر بعض الجهات التنظيمية برمجيات التوجيه حسب الأعراض "برمجيات كجهاز طبي (SaMD)". شروط Gemini تمنع أيضاً الاستخدام "بطريقة تتطلب موافقة جهة تنظيم الأجهزة الطبية" [SRC-006]. **يجب الحصول على رأي تنظيمي** للولاية المستهدفة قبل الإطلاق العام (OQ-024). تصميم رفيق يقلل المخاطر (لا تشخيص، توجيه عام، قواعد معلنة) لكنه لا يحسم التصنيف.
