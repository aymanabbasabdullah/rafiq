# تعريف الإنجاز (Definition of Done)

> الحالة: Draft · آخر تحديث: 2026-11-15 · ينطبق على كل Backlog Item وكل Module، بالإضافة إلى "Definition of Done" الخاص بكل Module.

## 1. على مستوى البند (Backlog Item)

**الكود**
- [ ] يتبع `laravel-best-practices` (Controllers رفيعة، Form Requests، Policies، `config()` لا `env()`، timeouts للـ HTTP، `mb_*`/`Str` للنص).
- [ ] `declare(strict_types=1)`؛ أنواع صريحة؛ TypeScript strict بلا `any`.
- [ ] لا نصوص واجهة حرفية؛ كل المفاتيح موجودة في `ar.json` و`en.json`.
- [ ] Logical CSS فقط؛ الأيقونات الاتجاهية معكوسة في RTL.
- [ ] Pint، ESLint، `tsc` نظيفة.

**الاختبار**
- [ ] Feature tests لكل سلوك جديد قابل للوصول بطلب، تشمل: نجاح، تحقق، تفويض، حالة حد.
- [ ] Unit tests لمنطق نقي جديد.
- [ ] الاختبارات المرتبطة بالمتطلبات الحرجة (Testing-Strategy §3) ما زالت تمر.
- [ ] لا طلبات شبكة خارجية في الاختبارات.

**الخصوصية والسلامة**
- [ ] لا بيانات صحية/تعريفية تُخزن أو تُسجل أو تُرسل خارج ما هو موثق في Data-Inventory.
- [ ] لا لغة تشخيصية أو طمأنة زائفة في أي نص جديد.
- [ ] أي نص طبي جديد موسوم Draft حتى الاعتماد.
- [ ] Threat-Model محدث إن تغيّر حد ثقة.

**ثنائية اللغة والوصول**
- [ ] فُحص بصرياً في `ar` (RTL) و`en` (LTR) على 360px و1280px.
- [ ] تنقل بلوحة المفاتيح؛ تسميات ARIA؛ تباين AA.

**المراجعة والتوثيق**
- [ ] مراجعة كود (Pull Request) من شخص آخر — أو مراجعة ذاتية موثقة باستخدام `/code-review` إن كان المطور وحيداً.
- [ ] الوثائق في `docs/` محدثة إن تغيّر سلوك أو قرار (ADR/OQ).
- [ ] CI أخضر.

## 2. على مستوى الوحدة (Module)

- [ ] كل معايير القبول في ملف الوحدة محققة.
- [ ] كل خطوات "Step-by-Step Implementation" منجزة أو مؤجلة بقرار موثق.
- [ ] "Open Questions" الخاصة بالوحدة: مغلقة أو مقبولة كافتراض موثق.
- [ ] Demo قصير للمالك.

## 3. على مستوى العناصر السريرية

- [ ] كل قاعدة/نص/سؤال له حالة صحيحة؛ لا شيء `Approved` دون اعتماد مسجل من Medical Reviewer ≠ المؤلف.
- [ ] TC-01..TC-37 (وأي حالات جديدة) تمر.
- [ ] Clinical-Rules-Catalogue وClinical-Test-Cases متطابقان مع ملفات JSON.

## 4. على مستوى الـ AI

- [ ] أي تغيير في CorePrompt/الإعدادات/النموذج يصحبه تقرير تقييم ناجح (AI-020).
